# AA25 Game Server Dashboard

Statisches Dashboard für GitHub Pages.

## Start
1. ZIP entpacken.
2. Dateien in ein neues GitHub-Repository hochladen.
3. Unter Settings -> Pages das Deployment von `main` / Root aktivieren.
4. Unter Actions kann `Update Server Status` manuell gestartet werden.

Die Datei `scripts/update_status.py` ist aktuell ein Platzhalter für den späteren AAtracker-Scraper.
